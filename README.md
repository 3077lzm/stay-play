# 学习打卡 · 能源动力大一工作台

一个**单页离线可用**的学习打卡工作台，基于你的课表 + 目标定制：

- **四门核心**：高等数学、线性代数、C/C++、工程图学 —— 按「上课当天必复习、非当天必预习/刷题」排，每天至少 2 门核心，权重最高。
- **英语四级（2027 年 6 月）**：每天早自习固定 20min 精听 + 25min 单词，重点补听力短板。
- **水课**（近现代史 / 体育 / 军事理论 / 健康素养 / 各类导论讲座）：平时到课、线上挂机，考前集中突击，不占日常自习。
- **影视飓风剪辑课**：当调剂项，学累了看、周末整块练，不挤占核心时段。
- 支持打卡、连续天数、本周完成率、分科投入统计、四级倒计时、一键导出/导入备份。

数据只存在手机浏览器本地（localStorage），**不会上传任何服务器**。

## 一、部署到 GitHub Pages（约 5 分钟）

> 你选的是方案 A：用 GitHub Pages 托管，iPhone 才能「添加到主屏幕」。

### 第 1 步：准备 GitHub 账号
没有就注册一个：<https://github.com/signup>（免费账号即可）。

### 第 2 步：新建仓库
1. 登录后点右上角 **+ → New repository**
2. **Repository name** 填：`study-plan`（或你喜欢的名字）
3. 勾选 **Public**（必须是 Public，免费 Pages 只支持公开仓库）
4. 点 **Create repository**

### 第 3 步：上传这 5 个文件
在新建的仓库页面，点 **Add file → Upload files**，把下面这些文件拖进去：

- `index.html`
- `manifest.webmanifest`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

然后点 **Commit changes**。

> 注意：一定要放在**仓库根目录**（不要放子文件夹里）。

### 第 4 步：开启 Pages
1. 仓库页面 → **Settings（设置）**
2. 左侧菜单找到 **Pages**
3. **Source** 选 **Deploy from a branch**
4. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
5. 等 1 分钟左右刷新页面，顶部的 **Your site is live at** 会给你一个网址，形如：
   `https://你的用户名.github.io/study-plan/`

### 第 5 步：iPhone 添加到主屏幕
1. 用 **Safari** 打开上面那个网址（别用微信/QQ 内置浏览器）
2. 点底部中间的 **分享按钮**（方框+向上箭头）
3. 往下滑，点 **添加到主屏幕**
4. 右上角点 **添加**

搞定！主屏幕上会多一个紫色勾勾图标，点开就是全屏的学习打卡 App。

## 二、日常使用

- **今日**：看今天的课 + 勾选自习任务，顶部圆环显示完成度。
- **周视图**：点任意一天展开，看当天课程和任务，也能直接勾。
- **统计**：连续打卡天数、累计完成、本周完成率、各科投入、四级倒计时。
- **我的**：改四级考试日期、开关深色模式、导出/导入备份、清空记录。

---

## 三、重要：数据备份

打卡记录存在**你手机浏览器**里。以下情况可能丢数据：

- 清除 Safari 网站数据 / 清理缓存
- iPhone 长期（数周）不打开这个 App，iOS 可能清理站点数据

**建议每周点一次「我的 → 导出备份」**，把 JSON 文件存到「文件」App 或 iCloud。换手机或数据丢了时，用「导入备份」恢复。

## 四、想自己调计划？

打开 `index.html`，找到 `const PLAN = {...}`，按天增删任务即可（`t` 时间、`s` 科目、`d` 描述、`tier` 权重、`min` 分钟）。改完重新上传覆盖即可。
